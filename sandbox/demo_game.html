Sprite Forge — tiny demo game

Loads a hermes.json sheet descriptor and plays each animation. This is the consumer contract — any Hermes Agent-generated 2D game just needs these ~60 lines of JavaScript to load sprites produced by Sprite Forge.

The JSON used here is test_sprites/cat_fighter_hermes.json. It was produced by running:
python3 src/analyzer.py test_sprites/cat_fighter.png -o test_sprites/cat_fighter_frames.json
python3 src/assembler.py from-analyzer --analyzer-json ... --by-row --row-names idle walk run punch kick stand
